# M0 milestone report — Foundation and Engineering Baseline

M0 is DONE. This report reconciles the persistent milestone record with the
evidence already captured in M0-013; it does not claim an external CI run that
was not observed.

## Delivered

- Rust workspace, pinned 1.98.0 toolchain, formatting and workspace lint policy.
- Shared error/failure conventions, layered Edge configuration, secret redaction,
  tracing/metrics, full-jitter backoff, and deterministic `TestClock` support.
- Authenticated Mosquitto with per-device ACLs and the Compose baseline.
- Dependency-free `rhizo-docscheck` integrated into the workspace and CI plan.

## Verification evidence

M0-013 records a fresh-clone run of the five then-current gate commands as green,
plus successful authenticated broker startup, refusal of anonymous and
cross-device publication, fail-fast invalid configuration, and redacted config
debug output. The workflow was checked structurally with `actionlint`; its
external GitHub execution remained deliberately unchecked because no committed
run had been observed.
