# M1 milestone report — Domain Model and MQTT Protocol

Completed 2026-08-27. All M1 issue verification and the project gate passed on
Rust 1.98.0. M2 implementation was not started.

## Delivered

- `rhizo-mqtt-contract`: `no_std` MQTT v1 topic, envelope, typed measurements,
  capabilities, time sync, command/config/status/policy/event payloads, and the
  single ordered `validate_water_command` implementation.
- `rhizo-policy`: pure `no_std` state/input/decision vocabulary for the bounded
  evaluator whose function body is explicitly assigned to M6-019.
- `rhizo-domain`: identifiers, stable state enums, clock abstraction, profile
  and sample primitives, and separate plant binding/policy concepts.
- Protocol fixtures: 12 valid and 5 invalid JSON compatibility artefacts.
- CI bare-metal builds for both firmware-shared crates.

## Measured implementation

- 11 concrete MQTT topic forms, all QoS 1; only status/config/policy retained.
- 11 message kinds and 11 known measurement kinds.
- Three capability structures: sensor, actuator, and their device declaration.
- `validate_water_command`: 12 ordered pure checks, 9 typed rejection variants,
  plus accepted and already-executed outcomes.
- Tests: mqtt-contract 30 (27 unit/property + 3 fixture), domain 2, policy 2.
- Property gate: 10,000 generated clamp cases.

Negative controls were executed and reverted: direct `Utc::now()` in the domain
failed the ADR-013 Clippy guard, and a `std::collections::HashMap` in the
contract failed the bare-metal build.

## Documentation corrections

M1-006 and PRD-010 still contained counts and scope fragments from the replaced
four-topic telemetry design. They now describe the normative ADR-017 batch and
the eleven current topic/message forms. Two Verification snippets that supplied
multiple Cargo test filters were split into valid commands. The protocol
conformance checklist now includes retained policy and explicitly excludes
retained time.

## Known limitations

The offline evaluator function body is intentionally not part of M1; current
issue M1-016 assigns it to M6-019. M1 supplies its shared embedded-compatible
contract and state vocabulary only. Transport, storage, simulator runtime, and
firmware remain later milestones.
